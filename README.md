EcoClean
A modern web-based application designed to promote sustainable waste management practices, reward eco-friendly behaviors, and build an active, environmentally conscious community.
Key Features
 * Location-Based Waste Disposal: Easily locate nearby recycling centers, specialized drop-off points, and public waste bins using integrated mapping tools.
 * Reward Points System: Earn redeemable points for logging responsible waste disposal and participating in green initiatives.
 * Educational Resources: Access a rich repository of articles, guides, and tips on recycling, upcycling, and minimizing your carbon footprint.
 * Community Engagement: Connect with fellow environmental advocates, join local clean-up drives, and participate in community-wide sustainability challenges.
Tech Stack
 * Frontend: HTML5, CSS3, JavaScript
Getting Started
Follow these instructions to get a local copy of the project up and running on your machine.
Prerequisites
Make sure you have Git installed on your system. A code editor like Visual Studio Code with the "Live Server" extension is recommended for local development.
Installation
 * Clone the repository:
   git clone https://github.com/Soumyadityaa/ecoclean2.0.git

 * Navigate to the project directory:
   cd ecoclean2.0

 * Open the project:
   * Open the index.html file directly in your web browser, or
   * Open the project folder in your code editor and launch it using a local development server (such as Live Server).
